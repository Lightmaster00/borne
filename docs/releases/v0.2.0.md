A new interface built for the couch, eight languages, and a launcher that is steadier from start to game.
- A new home: recently played games and collections, the game in a glass window, its case in 3D turned with the stick and its video in full screen
- The Store by console, as slanted cards lit from above; choose each console's picture (X), its order and its own folder
- One loading ring from launch to library, and a library that stays usable while a large sync runs
- Search reaches every match, across every console, from a single search page
- Eight interface languages: English, French, Spanish, Italian, German, Portuguese, Japanese and Simplified Chinese
- Fewer, clearer settings; the technical ones (every emulator option, a console's own picture and controls, each controller button) wait in developer mode
- Developer mode: open an emulator on its own interface, give it extra arguments, add emulators of your own
- Updates in one place: Borne and its emulators, with visible progress when an emulator updates
- Controls on three levels (every game, a console, a game), buttons set by pressing them; games made for an accessory are told before playing
- Switch: Eden and Ryubing stand in for each other; .nsz unpacked; updates and DLC; the player's keys checked first
- PS Vita with Vita3K, Wii U with Cemu, Saturn and 3DS fixes, Flatpak emulators closed with the game
- Safe mode no longer turns videos and sounds off for good; many fixes from testing on ChimeraOS and macOS
