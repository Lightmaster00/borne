The first stable release of Borne: a controller-driven launcher for your RomM library, on Linux
(ChimeraOS, SteamOS, any desktop) and macOS.
- Profiles ("Who's playing?") bound to RomM accounts, paired from the phone without a keyboard
- Your library offline too: consoles, favourites, recently played, genres, search, play time
- Download a game or play it straight from the network; archives extracted, multi-disc games handled
- The right emulator installed, updated and configured for each console: RetroArch, PCSX2, DuckStation, Dolphin, melonDS, Azahar, RPCS3, shadPS4, Vita3K, Eden, Citron, Ryubing
- Settings per console: its emulator, that emulator's options for all its games, picture and system files (BIOS from RomM, a file or a link); a game can have its own
- Controllers set up in every emulator, several players, buttons for every game or one game
- Escape or Select + Start: Borne asks before quitting a game, whatever the emulator
- Saves kept on RomM for each profile, taken before a game and sent after it
- Cheats from public databases (libretro, DeadSkullzJr's DS list, Dolphin, switch-cheats-db)
- Case scans, cartridges and logos from ScreenScraper; titles and summaries in the interface's language
- Added to Steam by itself, with its artwork (ChimeraOS through Chimera); uses the emulators already on your computer, AppImages in ~/Applications included
- Updates signed and downloaded by parts: a usual update weighs a few MB
- English and French interface
